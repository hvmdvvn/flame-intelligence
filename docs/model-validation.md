# Predictive feasibility

No predictive model is trained or exposed. `/api/models` reports `unavailable`, a null evaluation, actual imported measurement/run counts and outstanding requirements. No scenario configuration yields a fire probability, certification or fabricated numerical prediction.

The preserved annotations contain one experimental spread-rate value and three published computational values, with incomplete atmospheric conditions and no independent test population. These cannot support a credible supervised predictor. PSI metadata tables are not raw calibrated run datasets and remain excluded from training/comparison.

Before enabling a model: acquire authorized run data; review target definitions, units, sensor calibration and uncertainty; document missingness and condition coverage; group train/validation/test splits by run or investigation **before** preprocessing; fit simple baselines; report held-out MAE/RMSE and uncertainty calibration with sample counts; verify extrapolation boundaries; version data checksums, software, hyperparameters and artifacts. A model must enforce its applicability domain and expose unsupported scenarios as unavailable. These are requirements, not completed training/evaluation claims.
